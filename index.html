// REAL-TIME ENGINEERING MATH

Physical Design Interactive Calculators

Instantly evaluate core semiconductor metrics with step-by-step formulas, design rules, and interview questions.

Dynamic Power

P = α · C · V² · f

Switching power consumed charging & discharging load caps.

Dynamic Power 20.25 mW
Interview Focus: Dynamic power scales quadratically with voltage ($V^2$). Clock gating reduces switching activity $\alpha$. Voltage scaling is the strongest lever to recover power budget.

Core Utilization

Util = (Cell Area / Core) %

Die area ratio consumed by standard cells & hard macros.

Utilization
65.0%
Optimal (60-75%)
Rule of Thumb: Starting floorplans target 60%–70% utilization. Starting above 75% invites catastrophic detailed routing congestion and eliminates room for post-CTS timing ECO buffers.

Setup Slack (Max Delay)

Slack = Required - Arrival

Timing closure margin at the capture register D-pin.

Setup Slack
+0.130 ns
MET (PASS)
Fix Order: 1. Upsize high-fanout drivers; 2. Swap HVT cells to LVT; 3. Pin swap & buffer insertion; 4. Useful skew (advance launch or delay capture).

Hold Slack (Min Delay)

Slack = Arrival - Required

Ensures data remains stable after active clock edge.

Hold Slack
+0.010 ns
MET (PASS)
Why Buffer? Hold violations are independent of clock period $T$. If fast data arrives before $T_{hold}$, you must insert delay cells/buffers or downsize drivers to intentionally slow data down.

Clock Skew

Skew = T_capture - T_launch

Arrival time delta between related launch and capture flops.

Clock Skew
+30.0 ps
Positive Skew
Useful Skew: Positive skew gives data more time to arrive (relaxes setup time), but steals margin from hold time. CTS tools balance this across all related paths.

Elmore Wire Delay

τ = 0.69 · R · C

Distributed RC interconnect propagation time constant.

Interconnect Delay 2.90 ps
Why Buffering? Unbuffered net delay grows quadratically ($L^2$). Inserting repeaters/buffers at regular intervals breaks the long net into linear delay segments ($\propto L$).

Electromigration (EM)

J = I / Area (W · T)

Current density check against foundry metallization limits.

Current Density
95.2 mA/µm²
EM VIOLATION
Fixes: Widen metal stripes, add redundant parallel vias, or reroute on thicker top metal layers (e.g. M7/M8) where current-carrying cross section is substantially larger.

Static IR Drop

V_drop = I · R_mesh

Ohmic supply voltage loss across power grid rails.

IR Drop
36.0 mV (4.0%)
PASS (< 5% VDD)
Impact on Timing: Reduced supply voltage makes transistors switch slower, introducing unexpected setup timing degradation. Add power straps and decrease mesh pitch to resolve.

Clock Uncertainty Budget

Uncert = Jitter + Skew + OCV + Margin

Total clock timing uncertainty budget deducted from cycle time.

Total Uncertainty
130.0 ps (13.0% of T)
ROBUST (< 15% T)
STA SDC Command: Specified via set_clock_uncertainty -setup 0.13 [get_clocks SYS_CLK]. In hold analysis, jitter is typically excluded because hold check compares the same clock pulse edge.

Wire Resistance & RC Delay

R = ρL/(WT), τ = 0.69·R·C

Distributed interconnect wire resistance and 50% Elmore delay.

Interconnect Metrics
R: 733.3 Ω | τ: 37.95 ps
MODERATE DELAY
Scaling Rule: As wire width scales down, wire resistance increases quadratically with cross-sectional area, making wire delay dominate over cell delay below 7nm nodes. Buffer insertion breaks long wires into sub-critical lengths.

Decoupling Capacitor (Decap)

C = (ΔI · Δt) / ΔV

Charge reservoir required to suppress dynamic supply voltage droop.

Required Decap Reservoir
0.60 pF Decap
Charge Reservoir Sized
Placement Rule: Decap cells provide instantaneous charge during clock edge transitions before current can travel from off-chip pads. However, decap cells add gate leakage power, so they must be placed selectively near hotspots.

Crosstalk Noise & Delay

τ = R_d · (C_g + k·C_c)

Signal integrity delta delay caused by Miller coupling capacitance.

Effective Stage Delay
Delay: 31.50 ps (+17.50 ps SI)
WORST-CASE SWITCH (k=2)
Miller Effect: When victim and aggressor switch simultaneously in opposite directions, the voltage change across $C_c$ is $2 V_{DD}$, doubling the effective coupling capacitance. Fix by shielding, increasing wire spacing, or upsizing victim driver.

Fixed In Strict Order 1 → 10

7. Max Tran / Cap DRVs

9. Static & Dynamic IR / EM

The Complete RTL-to-GDSII Journey

Explore the industry-standard ASIC Physical Design flow stages, input/output collateral, and closure objectives. Click any step to inspect details.

01

1. Specification & RTL Architecture

Front-End

Defining architectural specifications, functional blocks, and coding synthesizable Verilog/SystemVerilog RTL. Verification, linting, and initial clock definitions are established.

Inputs
Architectural Specs, PRD, ISA Definition
Outputs
Verified RTL (.v / .sv), Testbenches
Key Objective
Bug-free synthesizable functional logic
02

2. Logic Synthesis & Netlist Generation

Synthesis

Converts technology-independent RTL code into a technology-dependent gate-level netlist using foundry standard cell libraries (.lib / .db) and Synopsys Design Constraints (.sdc).

Inputs
RTL (.v), Timing Constraints (.sdc), Target Libs (.lib)
Outputs
Gate-Level Netlist (.v), Synthesis SDC, Area/Power Reports
EDA Tools
Design Compiler, Yosys, Genus
03

3. Floorplanning & Power Mesh (P/G)

Physical Design

Establishes core & die boundaries, aspect ratio, utilization targets, macro placement with keepout halos, I/O pin allocation, and low-impedance VDD/VSS power rings and straps.

Critical Cells
Tap cells (latchup), End-cap cells, Decap cells
Key Metrics
Core Utilization %, Aspect Ratio (H/W), IR Drop bounds
Blockages
Hard, Soft, and Partial density blockages
04

4. Standard Cell Placement & HFNS

Core Optimization

Automated global placement, legalization to standard cell row sites, scan-chain reordering, high fanout net synthesis (HFNS), and timing-driven cell sizing / Vt swapping to eliminate setup violations.

Placement Stages
Coarse Placement → Legalization → Detailed Opt
Key Checks
Congestion Hotspots, WNS, TNS, Wirelength minimization
EDA Command
legalize_placement, report_congestion
05

5. Clock Tree Synthesis (CTS)

Clock Network

Synthesizes a low-skew, balanced clock distribution network across sequential registers using symmetric clock buffers/inverters, NDR routing rules (double width/spacing), and Integrated Clock Gating (ICG).

Clock Metrics
Clock Skew (Local & Global), Insertion Latency, Jitter
Exceptions
Stop pins, Exclude pins, Float pins (macros)
EDA Command
clock_opt (ICC2 / Innovus)
06

6. Routing & Signal Integrity

Interconnect

Executes Global Routing to plan paths through G-cells, followed by Detailed Routing to assign wires to precise metal tracks and via layers. Fixes crosstalk glitches, delta delay, and antenna effect violations.

Phases
Global Routing → Track Assignment → Detailed Routing
Reliability Fixes
Antenna Diodes, Metal Hopping, Net Shielding (VDD/VSS)
EDA Command
route_global, route_auto
07

7. Physical Verification & Signoff

Signoff Quality

Final rigorous checks: Design Rule Check (DRC) against foundry design rules, Layout Versus Schematic (LVS) equivalence, Electrical Rule Check (ERC), and Multi-Corner Multi-Mode (MCMM) Static Timing Analysis.

Verification Checks
DRC, LVS, ERC, Antenna, Electromigration (EM), IR Drop
Timing Signoff
Setup Slack ≥ 0, Hold Slack ≥ 0, Max Transition/Cap
Tools
PrimeTime, Calibre, IC Validator, OpenSTA
08

8. Tape-Out & Mask Data Preparation

Silicon Foundry

Final layout streaming to industry-standard GDSII / OASIS stream format for optical lithography mask manufacturing at the foundry fab (TSMC, Intel, GlobalFoundries, SkyWater).

Output Formats
GDSII (.gds), OASIS (.oas), MEBES
Final Artifact
Photomasks for photolithography fabrication
Next Milestone
Wafer fabrication, Packaging, Post-silicon bringup
